# Prompt 2 — Adding Swagger UI

## Prompt

How to add Swagger to the application?

**Requirements:**

- Enable API documentation UI.

## Response

FastAPI includes Swagger UI automatically at the `/docs` endpoint with zero configuration. No additional code or dependencies are needed.

**Key decisions:**

- No changes required; Swagger UI is built into FastAPI and available by default at `http://127.0.0.1:8000/docs`.

**Files affected:**

- None.
